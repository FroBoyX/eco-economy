# Profession Pricing Records

Each Eco profession should ultimately receive a dedicated file describing both its economics and its role in the shared progression chain.

## Required Questions For Every Profession

A profession record should answer:

- What inputs does the profession depend on?
- Which other professions should supply those inputs?
- What products/services create its early-game income?
- What canonical prices are LOCKED, DERIVED, PROVISIONAL, or RECOVERED?
- At low efficiency, can the profession earn a shallow positive margin?
- Which efficiency gains increase that margin as the player progresses?
- Which downstream professions/customers depend on its output?
- Does government buy or sell any of its goods, and why?
- Could a government shop accidentally bypass this profession?
- What pollution, waste, or resource-extraction externalities does it create?
- What waste does it generate that can feed Recycling?
- Can recovered materials substitute for any of its virgin inputs?
- What laws, districts, subsidies, or public works materially affect it?
- What progression bottleneck would occur if nobody chose this profession?

## Standard Price Table

Use a table shaped roughly like:

| Item | Government Buy | Reference Retail | Government Sell/Import | Status | Cost Basis | Notes |
|---|---:|---:|---:|---|---|---|

Not every item needs all three prices.

## Efficiency Model

Where practical, a profession file should show at least two cost states:

- **entry / inefficient producer**;
- **established / efficient producer**.

The reference sale price should normally remain the same between those states. The difference in effective production cost demonstrates the progression reward.

## Cross-Profession Rule

No profession file is an isolated price sheet.

Changes to one profession must be checked against upstream suppliers, downstream consumers, research progression, public works, pollution policy, and Recycling before being treated as final.
