# Eco Server and Run Profiles

This directory contains server/playthrough-specific state.

The reusable Eco 14 framework lives in the root domain directories. A run profile records how that framework is being applied to one actual server or playthrough.

## Rule

Do not move a run-specific choice into the reusable framework merely because it works well for one server.

Do not force all runs to inherit another run's names, colors, exact prices, laws, shortages, progression state, or political structure.

Each run should contain only its current canonical state. Git history is sufficient for prior versions.
