# Ironwood Run

Ironwood is the current Eco 14 server/run profile.

It is **not** the identity of the reusable `eco-economy` project.

This directory owns Ironwood-specific state such as:

- settlement, institution, and government names;
- exact prices chosen for this run;
- local laws and public works;
- server-specific profession participation;
- current shortages and progression state;
- treasury and exchange policy;
- visual identity and presentation colors.

Reusable pricing methods, profession models, recycling theory, government architecture, and rendering tools should remain outside this directory unless they are specific to Ironwood.
