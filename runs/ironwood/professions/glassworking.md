# Ironwood Glassworking — Glass Foundation

Derived from Eco 14 Core using current Ironwood anchors and entry-skill efficiency.

Derived producer costs use Town Buy/producer values for intermediate inputs. The Exchange retail spread is applied after the producer value is established.

## Limestone policy

Limestone remains strategically distinct from the common 0.10 rock tier.

**Limestone: 0.15 Town Buy / 0.17 Town Sell.**

This premium is justified by exact downstream demand in Quicklime, Glass, Cement and later industry.
