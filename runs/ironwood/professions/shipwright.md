# Ironwood Shipwright — Current Steam-Era Table

Rebuilt from the supplied Eco 14 Core using only current Steam-entry materials and workstations.

Shipwright has a clear depth progression: ropes/planks/frames are components; moorage and shipyards are infrastructure; complete canoes, barges, boats and ships are terminal end-use goods and receive the larger Ironwood terminal windfall.

The permanent current Ironwood Iron Bar baseline is **3.00 Town Buy / 3.15 Town Sell**. Current Shipwright recipes that consume Iron Bars or verified iron-chain components are repriced through to completed vessels below.
