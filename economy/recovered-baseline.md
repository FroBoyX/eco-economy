## Waste And Recycling Starting Posture

Before recycling creates useful recovered inputs, garbage is intended to operate as a **pay-to-take** system:

- negative government intake prices mean the public waste system pays players to surrender garbage;
- the immediate purpose is to make responsible disposal economically preferable to abandonment/dumping;
- prices should open upward into positive recovered-material value only when recycling gives the waste a legitimate productive use.

**Status:** RECOVERED — PREVIOUSLY LOCKED as the current design direction.

Exact negative values by garbage type are **RECOVERY NEEDED / ACTIVE BALANCE WORK**.

## Recovery Rule

When recovering a prior price or law:

1. prefer screenshots, pasted tables, repository evidence, or explicit user confirmations over model memory;
2. compare it against current locked anchors;
3. mark it with status;
4. record why it changed if it supersedes a prior value;
5. update dependent prices rather than leaving inconsistent downstream tables.
